01 · Compaction

        
Old turns fold into one summary. Tool calls never split.

        
Each turn is an assistant message with the tool calls it made and their results. Compaction cuts only at the start of an assistant turn, so a turn and its results always move together.

      


      
    
        
  1. 1
    Measure
    Before each request, quill estimates the size of the transcript at about four characters per token.
    2. 
        
  2. 2
    Fold
    Past 80% of the budget, every turn older than the last two is replaced by one summary message.
    3. 
        
  3. 3
    Keep pairs
    The last two turns stay verbatim with their results, and the latest request is kept too. The pairing is checked after every compaction.

02 · Design

        
Cut in the one place that keeps the protocol valid.

        
Cutting before a user message would make a single long turn impossible to compact, because the whole turn would be the only thing left to keep. Cutting before an assistant message keeps the last two assistant turns and the latest user request verbatim, and the pairing holds by construction.

        
Tool output is cut in the middle, not dropped. The head and tail stay, with a marker showing how many characters were removed, so a long log still shows where it starts and ends.

        
Each session is an append-only JSONL file. A compaction record stores the compacted history, so --resume replays that snapshot and never calls the summariser again.

        
Sub-agents are one level deep

        
The task tool starts a child with an empty history, read-only tools, and no permission to ask. The child cannot call task, so the tree cannot grow. The parent receives only the child's final text.

04 · Quickstart

        
Run the tests and both demos without a key.

        
Requires Bun 1.3 or later. The demos drive the real loop and real tools with a scripted model, so they run offline.

        
With a real model, set ANTHROPIC_API_KEY in .env and run bun src/cli.ts. Other providers are reached through QUILL_OPENAI_BASE_URL. The live path has not been run against a real API in this repo.

      

      

        
bun install

        
make test80 tests: loop, tools, path confinement, compaction, sub-agents, sessions

        
make demoa bug fixed in a temp repo, tests go red then green

        
make demo-compactionfour requests under a 1200-token budget

        
bun src/cli.ts -p "add a test for parse()"one-shot run with a real model, after setting a key

      

    

  


  
  

    

      

        
05 · Where to look

        
The hard part is five files.

      

      
    
        
  • 
          src/agent/compact.ts
          
    Cuts only at assistant messages and keeps the last two turns and the request verbatim. Everything older becomes one summary.
    
        
    • 
        
  • 
          src/agent/pairing.ts
          
    The provider's invariant written as code: every tool_use has exactly one tool_result in the next message. Run after every compaction.
    
        
    • 
        
  • 
          src/agent/loop.ts
          
    The turn loop. Compaction runs before each request, and a reply cut off at the output limit has its tool calls dropped rather than run.
    
        
    • 
        
  • 
          src/tools/paths.ts
          
    resolveInside() rejects .., absolute paths outside the root, NUL bytes, and symlinks that point out.
    
        
    • 
        
  • 
          src/agent/subagent.ts
          
    A child starts with an empty history, denies every permission request, and returns only its final text.

06 · Limits

        
What is not verified, stated plainly.

        
The replay is recorded output from the repository's own demos. Nothing here has been checked against a live model.

      

      
    
        
  • No live model run is verified. The Anthropic path is tested against a mock SSE server and the OpenAI path against a fake fetch.
    • 
        
  • bash is not a sandbox. Confinement covers the file tools only. The approval prompt is the guard for shell commands.
    • 
        
  • Token counts are estimates. Four characters per token can be off for code and non-English text.
    • 
        
  • One turn can still overflow. Compaction runs only between turns. A single request that is too big is reported as a warning.
    • 
        
  • Summaries are written by the model. Earlier facts survive only as far as the summary keeps them.
    • 
        
  • The OpenAI-compatible path is not streamed. The full reply arrives at once.
    •
