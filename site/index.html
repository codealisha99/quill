A terminal coding agent in TypeScript (Bun).

When the context runs out, quill folds the old turns and keeps every tool call paired.

Most agent loops fail the same way: the transcript outgrows the budget, and a summary or cut lands between a tool_use and its tool_result. The provider rejects the next request and the session is lost. quill cuts only at assistant turns, so the pairing holds by construction and is checked in the tests.

How the context is kept small

    
Each request is measured before it is sent, at about four characters per token. Past 80% of the budget, quill summarises the older turns into one user message, then sends the request. The cut is only ever made before an assistant message, which keeps the last two assistant turns and the latest user request verbatim. Cutting before a user message would make a single long turn impossible to compact.

    
Tool output is cut in the middle, not dropped. The head and tail stay, with a marker showing how many characters were removed. Each session is an append-only JSONL file. A compaction record stores the compacted history, so --resume replays that snapshot and never calls the summariser again.


    
Sub-agents are one level deep

    
The task tool starts a child with an empty history, read-only tools, and no permission to ask. The child cannot call task, so the tree cannot grow. The parent receives only the child's final text, so a long search does not fill the parent's context.


    
  


  

    
Quickstart

    
Requires Bun 1.3 or later. No API key is needed for the demos or the tests.

    
bun install
make test              # 80 tests: loop, tools, path confinement, compaction, sub-agent fan-out, sessions
make demo              # keyless: agent finds and fixes a bug in a temp repo, tests go red -> green
make demo-compaction   # keyless: four requests under a 1200-token budget; compaction triggers

    
With a real model, set ANTHROPIC_API_KEY in .env and run bun src/cli.ts. Other providers are reached through QUILL_OPENAI_BASE_URL. The live path has not been run against a real API in this repo.

  


  

    
Limits, stated plainly

    
    
      
  • No live model run is verified. The Anthropic path is tested against a mock SSE server and the OpenAI path against a fake fetch.
    • 
      
  • bash is not a sandbox. Confinement covers the file tools only. The approval prompt is the guard for shell commands.
    • 
      
  • Token counts are estimates. Four characters per token can be off for code and non-English text.
    • 
      
  • One turn can still overflow. Compaction runs only between turns. A single request that is too big is reported as a warning.
    • 
      
  • Summaries are written by the model. Earlier facts survive only as far as the summary keeps them.
    • 
      
  • The OpenAI-compatible path is not streamed. The full reply arrives at once.
